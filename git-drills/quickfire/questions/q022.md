# topic: rebase current branch onto main
---SCENARIO---
You're on `feature/x`, which diverged from main two commits ago. Main has since moved on. You want to replay your commits on top of main's new tip (no merge commit).

What command?
---ACCEPT---
git rebase main
---CANONICAL---
git rebase main
---EXPLAIN---
Rewrites your branch's commits with new SHAs. Don't do this on commits you've
already pushed to a shared branch.
