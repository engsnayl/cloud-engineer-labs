# topic: stage parts of a file interactively
---SCENARIO---
You've made several changes to `app.py` but only want to stage SOME of them - you want git to walk you through each chunk and ask whether to stage it.

What command?
---ACCEPT---
git add -p app.py
git add --patch app.py
git add -p
git add --patch
---CANONICAL---
git add -p app.py
---EXPLAIN---
`-p` is short for `--patch`. Indispensable for keeping commits focused. Hit
`?` at the prompt for the full list of options (y/n/s/e/q/...).
