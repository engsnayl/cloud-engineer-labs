# category: inspection
# difficulty: 2
# topic: history of one file
---SCENARIO---
You want to see every commit that touched `config.yaml`, with each commit's subject line.

What command?
---ACCEPT---
git log --oneline config.yaml
git log --oneline -- config.yaml
git log config.yaml
git log -- config.yaml
---CANONICAL---
git log --oneline config.yaml
---EXPLAIN---
The `--` separator (e.g. `git log -- config.yaml`) is good practice when the
filename might be ambiguous with a branch name. Add `-p` to see diffs.
