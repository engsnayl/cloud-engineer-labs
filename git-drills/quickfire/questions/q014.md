# topic: stage all tracked changes and commit
---SCENARIO---
You've modified several tracked files and want to commit them all in one go with the message "Refactor", without separately running `git add`.

What command?
---ACCEPT---
git commit -am "Refactor"
git commit -am 'Refactor'
git commit -a -m "Refactor"
git commit -a -m 'Refactor'
---CANONICAL---
git commit -am "Refactor"
---EXPLAIN---
`-a` auto-stages MODIFIED and DELETED tracked files. It does NOT stage new
(untracked) files - you'd need `git add` for those first.
