# topic: un-stage everything
---SCENARIO---
You ran `git add .` and immediately regretted it - too much got staged. You want to un-stage ALL staged changes (but keep them on disk).

What command?
---ACCEPT---
git restore --staged .
git reset
git reset HEAD
---CANONICAL---
git restore --staged .
---EXPLAIN---
Plain `git reset` (no args) un-stages everything. `git restore --staged .` is
the modern equivalent and is more explicit.
