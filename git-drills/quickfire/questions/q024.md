# topic: abort an in-progress rebase
---SCENARIO---
Mid-rebase, you've hit a conflict you don't have time to resolve. You want to back out and return to where you were before starting the rebase.

What command?
---ACCEPT---
git rebase --abort
---CANONICAL---
git rebase --abort
---EXPLAIN---
Always available during a rebase. After fixing conflicts you'd `git add` the
resolved files then `git rebase --continue` instead.
