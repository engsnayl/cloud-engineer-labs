# topic: commit with inline message
---SCENARIO---
Everything you want is staged. Make the commit, with the message "Fix login bug", in one command (no editor).

What command?
---ACCEPT---
git commit -m "Fix login bug"
git commit -m 'Fix login bug'
---CANONICAL---
git commit -m "Fix login bug"
---EXPLAIN---
`-m` skips the editor. Quotes can be single or double. For a multi-line
message use multiple `-m` flags or just omit `-m` to open your editor.
