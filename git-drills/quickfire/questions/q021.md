# topic: force a merge commit (no fast-forward)
---SCENARIO---
Your team's convention is that PR merges into `main` must always create a merge commit, even if a fast-forward would be possible. You're merging `feature/x` into the current branch.

What command?
---ACCEPT---
git merge --no-ff feature/x
---CANONICAL---
git merge --no-ff feature/x
---EXPLAIN---
Preserves the topology - you can see which commits were part of a PR. Some
teams prefer this; others prefer rebased linear history.
