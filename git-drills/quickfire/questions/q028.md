# topic: show recent HEAD positions
---SCENARIO---
You think you lost a commit after a bad reset. You want to see every position HEAD has been at recently so you can find the lost commit's SHA.

What command?
---ACCEPT---
git reflog
git reflog show HEAD
---CANONICAL---
git reflog
---EXPLAIN---
Reflog entries live for ~90 days by default. Branch-specific reflog: `git
reflog show <branch>`.
