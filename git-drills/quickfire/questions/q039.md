# topic: push all tags to origin
---SCENARIO---
You've created some local tags and want to push them all to `origin`.

What command?
---ACCEPT---
git push origin --tags
git push --tags origin
git push --tags
---CANONICAL---
git push origin --tags
---EXPLAIN---
Tags don't push automatically with `git push`. `--follow-tags` is a middle
ground: pushes annotated tags reachable from pushed commits.
