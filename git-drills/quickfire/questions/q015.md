# topic: create and switch to a new branch
---SCENARIO---
You're on `main`. Create a new branch called `feature/x` and switch to it in one command.

What command?
---ACCEPT---
git switch -c feature/x
git checkout -b feature/x
---CANONICAL---
git switch -c feature/x
---EXPLAIN---
`switch -c` is the modern spelling. `checkout -b` still works. `switch` was
added in git 2.23 specifically to avoid `checkout`'s overloading.
