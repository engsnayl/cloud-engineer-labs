# topic: see who changed each line
---SCENARIO---
You're staring at a confusing line in `app.py` line 42. You want to know which commit changed that line and who made the change.

What command?
---ACCEPT---
git blame app.py
git blame -L 42 app.py
git blame -L42 app.py
---CANONICAL---
git blame app.py
---EXPLAIN---
Add `-L 42,42` to focus on a specific line range. Some teams call this `git
annotate` (older alias).
