# topic: push new branch and set upstream
---SCENARIO---
You created a local branch `feature/x` and want to push it to origin AND set it as the tracking branch so future `git pull` and `git push` just work.

What command?
---ACCEPT---
git push -u origin feature/x
git push --set-upstream origin feature/x
---CANONICAL---
git push -u origin feature/x
---EXPLAIN---
After this, plain `git push` and `git pull` work from `feature/x`. Otherwise
you'd get 'no upstream branch' errors.
