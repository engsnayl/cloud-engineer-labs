# topic: list all branches including remote
---SCENARIO---
You want to see every branch this repo knows about - both local AND remote-tracking branches.

What command?
---ACCEPT---
git branch -a
git branch --all
---CANONICAL---
git branch -a
---EXPLAIN---
`-a` shows local + remote-tracking refs. `-r` shows only remote-tracking.
Plain `git branch` shows only local.
