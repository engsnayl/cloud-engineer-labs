# topic: fetch updates without merging
---SCENARIO---
You want to download all new commits, branches, and tags from `origin` WITHOUT changing your working tree or current branch.

What command?
---ACCEPT---
git fetch origin
git fetch
git fetch --all
---CANONICAL---
git fetch origin
---EXPLAIN---
Updates `origin/*` tracking refs but leaves your branches alone. `git pull` is
`fetch` + `merge` (or `+rebase` with `--rebase`).
