# topic: continue rebase after fixing conflict
---SCENARIO---
You're mid-rebase, hit a conflict, fixed the affected files, and ran `git add` on them. What command tells git to keep going with the rebase?
---ACCEPT---
git rebase --continue
---CANONICAL---
git rebase --continue
---EXPLAIN---
If after fixing the conflict you decide the commit is no longer needed, use
`git rebase --skip` instead to drop that commit entirely.
