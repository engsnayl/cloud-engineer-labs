# topic: merge a branch into current
---SCENARIO---
You're on `main`. You want to merge `feature/x` into main using the default merge strategy.

What command?
---ACCEPT---
git merge feature/x
---CANONICAL---
git merge feature/x
---EXPLAIN---
Defaults to fast-forward when possible, otherwise creates a merge commit. Add
`--no-ff` to force a merge commit even for fast-forwardable merges.
