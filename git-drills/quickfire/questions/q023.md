# category: rebasing
# difficulty: 3
# topic: interactive rebase last 3 commits
---SCENARIO---
You want to squash, reorder, or edit messages on the last 3 commits of your current branch BEFORE opening a PR.

What command?
---ACCEPT---
git rebase -i HEAD~3
git rebase --interactive HEAD~3
---CANONICAL---
git rebase -i HEAD~3
---EXPLAIN---
Opens an editor showing the 3 commits with 'pick' next to each. Change `pick`
to `squash`, `fixup`, `reword`, `edit`, `drop`, or reorder lines.
