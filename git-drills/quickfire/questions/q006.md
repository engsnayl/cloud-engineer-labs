# category: inspection
# difficulty: 2
# topic: view a specific commit
---SCENARIO---
Someone mentioned a commit with SHA `a1b2c3d` in a Slack message. You want to see what changed in that commit - both the message and the diff.

What command?
---ACCEPT---
git show a1b2c3d
git show a1b2c3
---CANONICAL---
git show a1b2c3d
---EXPLAIN---
`git show` defaults to HEAD if no ref given. Works on tags too: `git show
v1.0`.
