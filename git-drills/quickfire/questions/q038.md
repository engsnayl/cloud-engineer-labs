# topic: create annotated tag at HEAD
---SCENARIO---
You want to tag the current commit (HEAD) as `v1.0.0` with the tag message "Release 1.0.0". You want an ANNOTATED tag (carries metadata, the right kind for releases).

What command?
---ACCEPT---
git tag -a v1.0.0 -m "Release 1.0.0"
git tag -a v1.0.0 -m 'Release 1.0.0'
---CANONICAL---
git tag -a v1.0.0 -m "Release 1.0.0"
---EXPLAIN---
`-a` makes it annotated (with author, date, message). Lightweight tags (`git
tag v1.0.0` with no `-a`) are just refs - fine for personal markers, not for
releases.
