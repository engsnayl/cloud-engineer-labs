# topic: delete a merged branch
---SCENARIO---
You merged `feature/x` into main and want to delete the now-redundant local `feature/x` branch. You want git to refuse if the branch ISN'T merged.

What command?
---ACCEPT---
git branch -d feature/x
git branch --delete feature/x
---CANONICAL---
git branch -d feature/x
---EXPLAIN---
Lowercase `-d` only deletes merged branches (safe). Uppercase `-D` force-
deletes even unmerged ones (data loss possible).
