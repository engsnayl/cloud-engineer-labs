# topic: diff between two branches
---SCENARIO---
You want to see all the changes that are on `feature/x` but not on `main` - the diff that would be applied if you merged feature/x into main.

What command?
---ACCEPT---
git diff main..feature/x
git diff main feature/x
git diff main...feature/x
---CANONICAL---
git diff main..feature/x
---EXPLAIN---
Two dots: diff between the tips. Three dots (`main...feature/x`) diffs from
the merge base - usually what you actually want for PR-style review.
