# difficulty: 2
# topic: discard unstaged changes to a file
---SCENARIO---
You've made changes to `experiment.py` that you now want to throw away completely - revert it back to what's at HEAD. The file isn't staged.

What command?
---ACCEPT---
git restore experiment.py
git checkout -- experiment.py
git checkout experiment.py
---CANONICAL---
git restore experiment.py
---EXPLAIN---
DESTRUCTIVE - the unstaged changes are gone with no reflog to recover them.
The old `git checkout -- file` still works but is being phased out.
