# topic: list files with conflicts
---SCENARIO---
You're in the middle of a merge that has conflicts. You want git to tell you which files have conflicts (unmerged paths).

What command?
---ACCEPT---
git diff --name-only --diff-filter=U
git status
---CANONICAL---
git status
---EXPLAIN---
Plain `git status` lists them under 'Unmerged paths'. For just the names as a
clean list: `git diff --name-only --diff-filter=U`.
