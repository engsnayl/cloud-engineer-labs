# topic: stash uncommitted changes
---SCENARIO---
You're in the middle of editing files but need to switch branches right now. You want to set your changes aside (not commit them) so you can come back to them later.

What command?
---ACCEPT---
git stash
git stash push
git stash save
---CANONICAL---
git stash
---EXPLAIN---
Stashes both staged and unstaged changes. Add `-u` to include untracked files,
`-m "msg"` to label the stash.
