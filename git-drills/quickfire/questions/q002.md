# topic: see what's staged, modified, untracked
---SCENARIO---
You just sat down at a teammate's machine. Before you do anything else
you want to see, in one command: which files are modified, which are
staged, which are untracked, and what branch you're on.

What's the command?
---ACCEPT---
git status
---CANONICAL---
git status
---EXPLAIN---
The single most-used git command. Always run it before reaching for
anything more aggressive. `-s` or `--short` gives a more compact view
useful in scripts.
