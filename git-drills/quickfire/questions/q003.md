# topic: compact commit history
---SCENARIO---
You want a one-line-per-commit summary of the history on the current
branch - SHA and subject only, newest first.

What's the command?
---ACCEPT---
git log --oneline
git log --pretty=oneline
---CANONICAL---
git log --oneline
---EXPLAIN---
`--oneline` is shorthand for `--pretty=oneline --abbrev-commit`.
Add `--graph` for an ASCII branch graph, `--all` to include other branches.
