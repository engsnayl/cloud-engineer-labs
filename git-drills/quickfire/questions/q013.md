# topic: amend without changing message
---SCENARIO---
You forgot to stage `logo.png` in your last commit. You've now staged it and want to fold it into the previous commit WITHOUT being prompted to edit the message.

What command?
---ACCEPT---
git commit --amend --no-edit
---CANONICAL---
git commit --amend --no-edit
---EXPLAIN---
`--no-edit` keeps the existing commit message. Very common follow-up to a
forgotten `git add`. Safe only before pushing.
