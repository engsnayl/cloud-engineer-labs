# topic: see staged changes
---SCENARIO---
You've staged some files but haven't committed yet. You want to see the actual line-by-line diff of what's IN THE INDEX (i.e. what would be committed if you ran `git commit` now).

What command?
---ACCEPT---
git diff --cached
git diff --staged
---CANONICAL---
git diff --cached
---EXPLAIN---
`--cached` and `--staged` are aliases. Plain `git diff` shows working-tree vs
index. `git diff HEAD` shows working-tree vs last commit (combines both).
