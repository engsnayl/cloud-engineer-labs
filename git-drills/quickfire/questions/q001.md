# topic: un-stage a file without losing changes
---SCENARIO---
You ran `git add secrets.txt` by accident. The file is now staged but
you don't want to commit it. You want to un-stage it WITHOUT touching
your changes on disk.

What single command un-stages just secrets.txt?
---ACCEPT---
git restore --staged secrets.txt
git reset HEAD secrets.txt
git reset secrets.txt
git rm --cached secrets.txt
---CANONICAL---
git restore --staged secrets.txt
---EXPLAIN---
`git restore --staged <file>` is the modern spelling. The older
`git reset HEAD <file>` still works and you'll see it in many tutorials.
`git rm --cached` also works for new files but has different semantics
for already-tracked files (it stages a deletion).
