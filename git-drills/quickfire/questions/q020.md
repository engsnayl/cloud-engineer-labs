# topic: abort an in-progress merge
---SCENARIO---
You started a merge and it's full of conflicts you don't want to deal with right now. You want to back out completely - get back to the pre-merge state.

What command?
---ACCEPT---
git merge --abort
---CANONICAL---
git merge --abort
---EXPLAIN---
Works as long as you haven't committed the merge yet. After committing, you'd
`git reset --hard ORIG_HEAD` to undo (ORIG_HEAD is set by merge).
