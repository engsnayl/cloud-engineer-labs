# category: remotes
# difficulty: 3
# topic: safer force push
---SCENARIO---
You amended a commit on a branch you'd previously pushed to your fork. You need to force-push - but you want to refuse the push if someone else has since pushed to that remote branch.

What command?
---ACCEPT---
git push --force-with-lease
git push --force-with-lease origin
---CANONICAL---
git push --force-with-lease
---EXPLAIN---
Safer than `--force`: it refuses if the remote moved unexpectedly. Still
dangerous on shared branches - prefer to never rewrite shared history.
