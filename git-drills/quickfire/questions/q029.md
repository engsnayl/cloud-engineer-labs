# topic: undo a pushed commit safely
---SCENARIO---
You pushed a bad commit to main. You don't want to rewrite shared history. You want to create a NEW commit that reverses the changes of commit `a1b2c3d`.

What command?
---ACCEPT---
git revert a1b2c3d
git revert a1b2c3
---CANONICAL---
git revert a1b2c3d
---EXPLAIN---
`revert` is the public, non-history-rewriting way to undo. `reset` would
rewrite history and require a force-push - dangerous on shared branches.
