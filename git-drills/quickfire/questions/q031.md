# topic: list remotes with URLs
---SCENARIO---
You want to see every remote this repo is configured with, AND each remote's URL (for fetch and push).

What command?
---ACCEPT---
git remote -v
git remote --verbose
---CANONICAL---
git remote -v
---EXPLAIN---
Plain `git remote` lists just names. `-v` shows the URLs and whether each is
for fetch or push.
