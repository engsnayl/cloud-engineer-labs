# topic: stage a single file
---SCENARIO---
You've edited `README.md` and want to stage just that one file for the next commit (nothing else).

What command?
---ACCEPT---
git add README.md
git add ./README.md
---CANONICAL---
git add README.md
---EXPLAIN---
`git add .` would stage everything in the current dir - useful but easy to
over-include. Stage by name when you're being deliberate.
