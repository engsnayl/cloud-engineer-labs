# topic: apply most recent stash and remove it
---SCENARIO---
You're back on the branch where you stashed earlier. You want to re-apply your most recent stash AND remove it from the stash list.

What command?
---ACCEPT---
git stash pop
git stash pop stash@{0}
---CANONICAL---
git stash pop
---EXPLAIN---
`pop` = apply + drop. `apply` keeps the stash on the list (useful if you want
to apply it to multiple branches).
