# category: rescue
# difficulty: 2
# topic: bring one commit from another branch
---SCENARIO---
You want to take just commit `a1b2c3d` from another branch and apply it on top of your current branch as a new commit.

What command?
---ACCEPT---
git cherry-pick a1b2c3d
git cherry-pick a1b2c3
---CANONICAL---
git cherry-pick a1b2c3d
---EXPLAIN---
Hotfix-friendly: take a fix from main back to a release branch with one
command. Multiple SHAs can be passed; conflicts pause the cherry-pick like a
rebase.
