# topic: rename current branch
---SCENARIO---
You're on a branch called `featur/x` (typo). You want to rename it - while standing on it - to `feature/x`.

What command?
---ACCEPT---
git branch -m feature/x
git branch --move feature/x
---CANONICAL---
git branch -m feature/x
---EXPLAIN---
`-m` renames the current branch when given one argument. With two args you can
rename any branch: `git branch -m old new`.
