# Solution Workspace

This folder is where the project is built **module by module** as part of the
capstone walkthrough. Each module has its own solution document at the project
root (e.g. `SOLUTION-MODULE-01-TERRAFORM.md`).

The complete reference build lives in `../reference/` for comparison — do not
run `terraform apply` from there.
